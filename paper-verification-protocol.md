# Paper Verification Protocol

**Research area:** IoT intrusion detection using ML

Use this checklist for every candidate paper before including it in the literature review. Fill every field with a web-verified fact and a source. Never fabricate a DOI, indexing status, quartile, impact factor, or CiteScore — write **"Not verified"** where a fact cannot be confirmed.

---

## Step 1 — Identify the Publication
- [ ] Exact paper title
- [ ] Authors
- [ ] Publication year
- [ ] DOI
- [ ] Publisher
- [ ] Exact journal name
- [ ] Volume, issue, and pages / article number
- [ ] Publication type (journal article, conference paper, review, etc.)

## Step 2 — Verify the Journal
- [ ] Journal or conference?
- [ ] ISSN / eISSN
- [ ] Publisher
- [ ] Scopus indexing status
- [ ] Web of Science indexing status (if applicable)
- [ ] Journal quartile (Q1/Q2/Q3/Q4) — **do not guess**
- [ ] Subject category the quartile applies to
- [ ] Whether the quartile applies to the paper's publication year specifically
- [ ] CiteScore / Impact Factor (JCR), if available
- [ ] Whether the journal is currently active
- [ ] Any journal-quality concerns (predatory publisher lists, delisting, etc.)

> If different databases or subject categories disagree on ranking, list them **separately** and explain the discrepancy — don't collapse them into one answer.

## Step 3 — Verify the Paper Itself
- [ ] Research problem
- [ ] Research objective
- [ ] Research question (if stated)
- [ ] Dataset(s) used
- [ ] Method / model / algorithm
- [ ] Baseline methods compared against
- [ ] Evaluation metrics
- [ ] Main results
- [ ] Main contribution
- [ ] Limitations
- [ ] Research gap addressed
- [ ] Is the methodology reproducible?
- [ ] Relevance to the thesis topic (IoT intrusion detection using ML)

## Step 4 — Research Relevance
Explicitly connect the paper's problem, dataset, and method back to **IoT intrusion detection using ML** — note overlap and any gaps it does *not* cover.

## Step 5 — Source Verification
Prioritize, in this order:
1. Official journal / publisher page
2. Scopus
3. Web of Science
4. Journal Citation Reports (JCR), if available
5. Crossref
6. Official DOI record

Every non-trivial factual claim must carry a source.

### Rules
- Search the web to verify current *and* historical information — never rely on memory alone.
- Never confuse the journal's quartile with the quality of the individual paper.
- Never assume Q1 (or any quartile) without verification.
- Clearly separate the journal's **current** ranking from its ranking **at time of publication**.
- If a fact cannot be verified, write "Not verified" — never fabricate DOI, indexing, quartile, impact factor, or CiteScore.
